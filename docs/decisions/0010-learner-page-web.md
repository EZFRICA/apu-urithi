# 0010: The learner's page stays a web page, with a tutor anchored to a path

Decided: 2026-10-05, by the owner.

## Context
The school tutor of this line had a conversational page that felt more practical; this project needs offline use, installation and the keyboard.

## Decision
The learner's page keeps its web stack and gains the tutor's features: text, voice or braille, a screen available or not, the notebook and revision sheets, the conversation anchored to the part in view, with the contents always visible.

## Consequences
Offline, installable and keyboard first remain guarantees.

## Alternatives set aside
- A Streamlit page: no offline use, no installation, weak keyboard control.
