# 0011: The classroom mode replaces the separate screen-watching page

Decided: 2026-10-05, by the owner.

## Context
Watching the guardian work was a page apart from teaching.

## Decision
A full-screen mode of the guardian's page: screen or camera, teleprompter, a board of what is captured, Urithi asking at the pauses. Urithi is the only pupil at first. What is captured goes to the working memory.

## Consequences
The root address becomes a static showcase of the features and components.

## Alternatives set aside
- Learners live from the start: a real-time multi-person project of its own.
